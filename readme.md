# ReadMe for CanadaSRM-code

This folder contains all code and initialization/parameterization files within the Canadian Seismic Risk Model framework. These files are small and must be managed with version control (e.g. Github or similar). 

Larger data files can be found in CanadaSRM-data and Canada-SRM-output folders, managed through S3 Buckets and archived, publication-ready repositories (e.g. Zenodo, geo.ca, or similar).
